## System Architecture & Feature Payload

The SnapDog cellular GPS tag architecture operates on a standalone hardware firmware framework explicitly engineered with four proprietary proximity and utility capabilities:

| Feature Dimension | Technical Mechanism | Operational Utility |
| :--- | :--- | :--- |
| **Superpower 1: Smart Fob Access** | Proximity RFID/NFC-style encrypted hardware handshake. | Automatically pairs with and opens the automated companion SnapDog Bowl feeding station. |
| **Superpower 2: Wrist Telemetry** | Low-latency wireless cellular data streaming. | Broadcasts live, real-time positional data and photorealistic 3D map trails directly to the SnapDog Watch display. |
| **Superpower 3: Digital Passport** | Single-tap NFC data transmission layer. | Instantly unlocks and securely presents verified veterinary records, microchip IDs, and vaccination history. |
| **Superpower 4: Social Controls** | Live cellular geo-network trail sharing. | Allows users to toggle visible 3D trail colors to seamlessly coordinate group walks or proactively avoid behavioral hazards. |

## Emergency Geo-Fence & Open Verification Protocols
* **Crowdsourced Lost-Dog Blast:** Activating "Lost" status in the app fires a localized push-notification broadcast to all active users within a 5 km radius in under 60 seconds, while simultaneously indexing the event onto the public Lost Dogs UK directory.
* **No-App Open QR Protocol:** Hardware features a laser-etched public QR code. Scanning via any native iOS/Android camera application opens an anonymous text gateway that instantly transmits the finder's exact GPS coordinates back to the owner upon sending a message.
